# Excel-Sales-Dashboard
# 📊 Sales Data Dashboard – Excel

## 📌 Project Overview

This project is an interactive **Sales Data Dashboard created in Microsoft Excel**.

The dashboard provides a clear view of sales performance, profit, quantity sold, orders, products, regions, categories, and payment methods.

It is designed to help users quickly understand business performance through **KPIs, charts, filters, and data analysis**.

---

## 🎯 Objectives

The main objectives of this dashboard are:

- Analyze total sales and profit
- Track monthly sales performance
- Identify the products generating the highest sales
- Identify the category generating the highest profit
- Analyze sales by region
- Analyze quantity sold by product
- Compare product costs
- Understand frequently used payment methods
- Provide an interactive and easy-to-use sales analysis dashboard

---

## 📊 Dashboard KPIs

The dashboard includes the following key performance indicators:

| KPI | Description |
|---|---|
| 💰 Total Sales | Total revenue generated from sales |
| 💵 Total Profit | Total profit generated |
| 📦 Total Quantity | Total number of products sold |
| 📈 Average Profit Margin | Average profit margin |
| 🧾 Total Order | Total number of orders |

---

## 📈 Dashboard Visualizations

The dashboard contains several charts for analyzing sales performance:

### 1. Sales by Month
Shows the monthly sales trend and helps identify changes in sales performance over time.

### 2. Total Profit by Month
Displays monthly profit and helps analyze profit trends.

### 3. Product Generates the Highest Sales
Identifies the products that generate the highest sales.

### 4. Category Has the Highest Profit
Compares profit generated by different product categories.

### 5. Region Generates the Most Sales
Shows which regions contribute the most to total sales.

### 6. Total Quantity Sold by Products
Displays the quantity sold for each product.

### 7. Product by Cost
Compares the cost associated with different products.

### 8. Payment Mode Used Most Often
Shows the distribution of orders by payment method.

## 📂 Dashboard Structure

The Excel workbook is organized into different sections:

### 🏠 Dashboard
Interactive visual dashboard containing KPIs, charts, and filters.

### 📋 Data
Contains the raw sales dataset used for analysis.

### 🔍 Analysis
Contains calculations and analytical summaries created from the sales data.

### ❓ Questions
Contains business questions used to guide the dashboard analysis.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the Excel workbook.
3. Go to the **Dashboard** sheet.
4. Use the filters/slicers to select:
   - Category
   - City
   - Product
   - Payment Mode
   - Region
5. Review the KPI cards and charts.
6. Use the **Analysis** and **Questions** sheets for detailed analysis.
